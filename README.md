## 🤔 The Problem

In a market flooded with generic fitness apps, users often face a "one-size-fits-all" approach that leads to boredom, discouragement, and poor results. Many apps lack true personalization, fail to integrate diet with exercise, and are built on outdated, slow architectures.

## ✨ The Solution

**FitZealot** tackles these issues head-on. It's an intelligent fitness partner that leverages the power of the **Google Gemini API** to create dynamic, adaptive, and hyper-personalized workout and diet plans. Built on a robust, event-driven microservice architecture, the platform is designed to be fast, reliable, and scalable from the ground up.

---

## 🚀 Key Features

-   **🤖 AI-Powered Plan Generation:** Get bespoke workout and diet plans generated by the Gemini API, tailored to your specific goals, preferences, and progress.
-   **🏋️ Custom Workout Planning:** Build and save your own workout routines from a comprehensive, built-in exercise library.
-   **📈 Dynamic Progress Tracking:** Log your workouts and meals, and visualize your journey with insightful charts and dashboards.
-   **🧮 Instant Health Calculators:** Quickly calculate your Body Mass Index (BMI) and estimated daily calorie needs.
-   **🔔 Real-Time Notifications:** Stay motivated with timely reminders, nudges, and celebratory messages.
-   **🤝 Community & Social Features:** Connect with friends and take on fitness challenges together to stay accountable.

## 🏗️ System Architecture

FitZealot is built using an **event-driven microservice architecture** to ensure scalability, resilience, and maintainability.

-   The **React.js Frontend** acts as the user interface.
-   An **API Gateway** serves as the single entry point for all requests, handling authentication and routing.
-   The backend consists of several independent **Spring Boot microservices**, each responsible for a specific business domain (Users, Workouts, AI, etc.).
-   Services communicate **asynchronously** using **Apache Kafka** as a message broker, ensuring loose coupling and real-time data flow.
-   All application data is persisted in a **MySQL** database, with each service managing its own schema.

## 🏁 Getting Started

Follow these instructions to get the project up and running on your local machine for development and testing purposes.

### Prerequisites

Make sure you have the following software installed on your system:
-   **Java JDK 17** or higher
-   **Apache Maven** or **Gradle**
-   **Node.js v18** or higher (with npm)
-   **Docker** and **Docker Compose**
-   **Git** for cloning the repository

### Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/fitzealot.git](https://github.com/your-username/fitzealot.git)
    cd fitzealot
    ```

2.  **Configure Environment Variables:**
    Create a `.env` file in the root directory of the project by copying the example file:
    ```bash
    cp .env.example .env
    ```
    Now, open the `.env` file and add your specific credentials and keys:
    ```env
    # MySQL Configuration
    MYSQL_DATABASE=fitzealot_db
    MYSQL_USER=your_mysql_user
    MYSQL_PASSWORD=your_mysql_password
    MYSQL_ROOT_PASSWORD=your_mysql_root_password

    # Kafka Configuration
    KAFKA_BROKER_ADDRESS=kafka:9092

    # Gemini API Key
    GEMINI_API_KEY=your_google_gemini_api_key

    # JWT Secret Key
    JWT_SECRET_KEY=your_super_secret_key_for_jwt_signing
    ```

3.  **Start Infrastructure with Docker Compose:**
    This command will start the necessary infrastructure services (MySQL and Kafka) in Docker containers.
    ```bash
    docker-compose up -d
    ```

4.  **Run Backend Microservices:**
    Navigate into each microservice's directory (e.g., `user-service`, `workout-service`, etc.) and run it using your IDE or the command line.

    For example, using Maven for the `user-service`:
    ```bash
    cd user-service
    mvn spring-boot:run
    ```
    *Repeat this step for all backend microservices.*

5.  **Run the Frontend Application:**
    Navigate to the `frontend` directory in a new terminal window.
    ```bash
    cd frontend
    npm install
    npm start
    ```
    The React development server will start, and you can access the application at `http://localhost:3000`.
